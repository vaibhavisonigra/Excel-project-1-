# Excel-project-1
📊 Excel Fundamental Booster Project

🚀 Learn Excel Fundamentals Through Practical Exercises

Welcome to the Excel Fundamental Booster Project!

This project is designed for beginners who want to learn Microsoft Excel through practical exercises, formulas, data analysis, and real-world examples.

The main goal is to build a strong foundation in Excel and develop the skills needed to organize, calculate, analyze, and visualize data effectively.

🧮 Practical Example

Student Marks Analysis

Student Name| Maths| Science| Total Marks| Result
Rahul| 85| 90| 175| Pass
Priya| 75| 80| 155| Pass
Amit| 30| 35| 65| Fail

Calculate Total Marks

=B2+C2

Alternatively:

=SUM(B2:C2)

Calculate Result

Assuming the passing requirement is at least 70 total marks:

=IF(D2>=70,"Pass","Fail")

These formulas demonstrate basic calculations and logical decision-making in Excel.
